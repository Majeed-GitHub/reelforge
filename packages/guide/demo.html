How to get an embed key

        
    
          
  • Run the API and seed a workspace: npm run seed.
    • 
          
  • 
            Record one demo against http://127.0.0.1:4402; completing it drafts a guide.
          
    • 
          
  • 
            List guides: curl http://127.0.0.1:4400/api/guides -H "X-API-Key: rg_…" — copy
            embed_key.
          
    • 
          
  • Publish it on the dashboard's Guides screen (or POST /api/guides/:id/publish).
    • 
          
  • 
            Open http://127.0.0.1:4400/g/demo.html?key=<embed_key> and press Load guide.
